# YiW 配色系统

日期：2026-07-15

## 目标

YiW 是面向多种工作场景的本地 AI 工作空间。配色需要适合长时间使用，并能覆盖数据、PDF、文档、研究和自动化等不同工作台。

本次调整彻底移除旧的紫色品牌体系，不再使用紫色、紫蓝渐变或带紫色倾向的深色背景。

## 核心颜色

| 作用 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 页面背景 | `#F3EFE5` 暖灰纸色 | `#202A25` 炭绿 |
| 内容表面 | `#FCFAF5` 暖白 | `#121815` 深炭绿 |
| 主要文字 | `#17211D` 墨绿黑 | `#F4EFE3` 暖白 |
| 次要文字 | `#66716B` | `#B9B4A9` |
| 主要操作 | `#17483E` 深绿 | `#E4B33F` 暖黄 |
| App 品牌强调 | `#FFD34E` 亮金黄 | `#FFD34E` 亮金黄 |
| Logo 品牌底色 | `#F1B434` 暖黄 | `#F1B434` 暖黄 |
| 选中背景 | `#FFF1B8` | `#2F3B31` |

成功、错误、警告和信息仍保留绿、红、黄、蓝的状态含义，但不参与品牌装饰。

## 使用规则

1. 主要按钮在浅色模式使用深绿底和暖白文字，不使用渐变。
2. Logo 保持原来的暖黄；App 内使用更亮的金黄，用于当前选中项、引导进度和少量重点提示，不作为大面积页面底色。
3. 深色模式采用炭绿背景，不使用带紫色倾向的黑灰。
4. 图表可以使用多种状态色，但色板中不再放入紫色和品红色。
5. Mantine、Element Plus、YiW 工作台和旧页面统一读取同一套品牌颜色。

以上关键组合均达到 WCAG AA 正文要求。

## 代码落点

- 默认主题改为 `yiw-warm`，旧的未知主题缓存会自动回退到该主题。
- Element Plus 主色改为深绿，选中态使用暖黄浅底。
- Mantine 主色改为 `yiw` 深绿色阶。
- YiW 工作台新增 `--yiw-brand`、`--yiw-brand-soft` 和 `--yiw-on-brand`。
- 页面硬编码、引导页、SQL 选区、上传进度、图表色板和半透明阴影中的紫色均已替换。
