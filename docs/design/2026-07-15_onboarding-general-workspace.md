# YiW 通用工作空间引导优化

日期：2026-07-15

## 问题

原来的首次引导以智能问数为中心：

- 欢迎页把 YiW 描述为本地数据工作台。
- 向量模型与主模型同时被视为必要配置。
- 工作区教程围绕问数项目、数据源、语义配置和 SQL 计划展开。
- 最后一步要求接入数据库或文件，并通过问数预览验证。

这会让用户误以为 YiW 只适合数据工作，也让第一次使用必须理解过多专用概念。

## 目标

首次引导只帮助用户完成一件事：进入一个工作空间，并知道如何开始第一个真实任务。

目标用户按普通办公用户与熟练用户混合处理。引导保持可跳过，不强迫用户先完成模型或数据配置。

## 新流程

### 1. 认识 YiW

说明 YiW 是本地 AI 工作空间，可以处理对话、文件、PDF、研究、方案和多步任务。

核心入口只保留：

- 开始对话
- 打开文件夹
- 调用技能

### 2. 可选模型设置

- 只把主模型作为建议配置。
- 向量模型与副模型改为按需配置。
- 没有配置模型也可以继续浏览和进入应用。
- 所有说明改为对话、文件处理、工具和多步任务，不再使用问数专用描述。

### 3. 开始工作

展示四种连续动作：

1. 直接开始对话。
2. 打开一个文件夹作为长期工作空间。
3. 加入 PDF、文档、图片或表格。
4. 交给 YiW 一个真实任务。

## 移除内容

首次引导中已移除：

- 问数项目
- 数据源接入教程
- 语义配置
- SQL 计划
- GMV 等数据示例
- 问数预览和问数成功标准
- 主模型加向量模型的双重必需判断

这些能力仍可在实际使用场景中按需出现，但不再定义 YiW 的首次体验。

## 验证

- `renderer/src/views/agent/onboarding` 中不再包含问数、SQL、数据源、语义配置或 GMV 文案。
- TypeScript 类型检查通过。
- 正式前端构建用于继续验证组件和样式引用。
