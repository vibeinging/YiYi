# 架构概述

YiW 采用双层权限模型：**系统级权限** + **项目级权限**。

## 核心概念

### 系统层

- **公司 (Company)** - 顶层组织单位
- **系统管理员** - 管理公司级别的设置

### 项目层

- **项目 (Project)** - 工作空间，数据隔离单位
- **成员 (Member)** - 项目中的用户
- **角色 (Role)** - 预定义的权限集合

### 权限层

6 个核心权限代码，详见[权限代码](/docs/developer/architecture/permissions)。

## 设计原则

1. **数据隔离** - 项目之间数据完全隔离
2. **最小权限** - 每个接口只需必要的最小权限
3. **路由层检查** - 所有权限验证在路由层完成
