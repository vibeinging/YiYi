# Agent Settings 系统使用指南

## 概述

Agent Settings系统统一管理所有Agent的配置，包括：
- System Prompt 配置
- User Prompt 模板
- 业务规则（通过{rules}占位符插入）
- LLM模型选择
- 数据库存储和实时更新
- 默认配置降级机制
- 性能优化的缓存系统
- 前端可视化管理界面

## 核心组件

### 1. Agent数据模型 (`backend/models/agent.py`)
```python
class Agent(BaseModel):
    name: str  # Agent名称
    agent_type: str  # Agent类型（nl2sql, question_enhancement, entity_replacement）
    user_id: str  # 用户ID
    database_connection_id: Optional[str]  # 数据库连接ID（可选，为空则为全局）
    model_id: Optional[str]  # LLM模型ID
    system_prompt: str  # System Prompt，支持{rules}占位符
    user_prompt_template: str  # User Prompt模板
    rules: Optional[str]  # 业务规则，通过{rules}占位符插入
    is_active: bool  # 是否启用
    is_default: bool  # 是否为默认Agent
```

### 2. AgentService (`backend/api/services/database/agent_service.py`)
核心服务类，提供：
- Agent配置的CRUD操作
- 带降级的配置获取
- 自动缓存管理
- 默认配置创建

### 3. Agent Settings 方法
AgentService提供多种获取Settings的方法：

- `get_nl2sql_settings()`: 获取NL2SQL配置
- `get_question_enhancement_settings()`: 获取问题增强配置
- `get_entity_replacement_settings()`: 获取实体替换配置
- `get_agent_config_with_default()`: 获取原始配置（可手动编译）

## 使用方式

### 方式1：直接使用AgentService（推荐）
```python
from api.services.database.agent_service import AgentService
from models.agent import AgentType

async def example_usage():
    async with async_session_factory() as db:
        agent_service = AgentService(db)

        # 获取Agent配置（自动处理降级）
        config = await agent_service.get_agent_config_with_default(
            user_id=user_id,
            agent_type=AgentType.NL2SQL,
            database_connection_id=database_id,
            rules=business_rules  # 编译时的额外参数
        )

        # 使用配置
        system_prompt = config['system_prompt']
        user_prompt_template = config['user_prompt_template']

        # 判断配置来源
        if config['from_db']:
            print("使用数据库配置")
        else:
            print("使用默认配置")
```

### 方式2：获取原始配置并手动编译
```python
from api.services.database.agent_service import AgentService

```

### 方式3：前端管理界面
通过 `AgentSettings.vue` 组件可视化配置：
- 访问路径：数据库管理 -> Agent配置
- 支持切换Agent类型
- 支持选择数据库连接
- 实时编辑和测试Prompt

## 默认配置

默认配置存储在 `config/prompt_templates.yaml`：
```yaml
templates:
  nl2sql_system:
    name: "NL2SQL 系统提示词"
    content: |
      你是一个专业的SQL查询生成专家...
      {business_rules}
```

### 自动创建规则
1. 新建数据库连接时，自动创建三个默认Agent
2. Agent类型：
   - `nl2sql`: NL2SQL Agent
   - `question_enhancement`: 问题增强Agent
   - `entity_replacement`: 实体替换Agent

## 缓存机制

Agent配置支持内存缓存：
- 缓存时间：5分钟
- 缓存键：`{user_id}:{agent_type}:{database_connection_id}`
- 更新配置时自动清除相关缓存

手动清除缓存：
```python
# 清除特定用户缓存
AgentService.clear_cache(user_id="user123")

# 清除所有缓存
AgentService.clear_cache()
```

## API接口

### Agent配置管理
```http
# 获取Agent配置
GET /agents/{user_id}/{agent_type}?database_connection_id=xxx

# 创建/更新Agent
POST /agents/{user_id}
{
  "name": "My Agent",
  "agent_type": "nl2sql",
  "system_prompt": "...",
  "user_prompt_template": "...",
  "rules": "业务规则",
  "model_id": "model_id",
  "database_connection_id": "db_id"
}

# 编译Prompt（替换占位符）
POST /agents/{agent_id}/compile
{
  "placeholders": {
    "rules": "动态规则"
  }
}

# 获取可用模型
GET /agents/models/available

# 获取可用数据库连接
GET /agents/connections/available
```

## 最佳实践

### 1. 使用占位符
```python
# System Prompt中使用占位符
system_prompt = """
你是SQL专家。

{rules}

请生成查询...
"""

# 编译时动态替换
config = await agent_service.get_agent_config_with_default(
    user_id=user_id,
    agent_type="nl2sql",
    rules="1. 使用索引\n2. 限制结果数量"
)
```

### 2. 分离全局和数据库特定配置
```python
# 全局配置（database_connection_id=None）
global_config = await agent_service.get_agent_config_with_default(
    user_id=user_id,
    agent_type="nl2sql"
)

# 数据库特定配置
db_config = await agent_service.get_agent_config_with_default(
    user_id=user_id,
    agent_type="nl2sql",
    database_connection_id="db123"
)
```

### 3. 使用默认模板
新Agent类型应该：
1. 在 `prompt_templates.yaml` 中添加默认配置
2. 更新 `get_default_agent_configs()` 函数
3. 更新 `AgentType` 常量

## 故障排查

### 问题1：配置未生效
1. 检查缓存：调用 `AgentService.clear_cache(user_id)`
2. 检查配置来源：查看 `config['from_db']` 返回值
3. 检查Agent是否激活：`is_active=True`

### 问题2：默认配置未加载
1. 检查 `prompt_templates.yaml` 文件是否存在
2. 检查模板格式是否正确
3. 查看日志中的加载错误

### 问题3：性能问题
1. 使用批量查询减少数据库访问
2. 利用缓存机制
3. 避免频繁更新配置

## 扩展指南

### 添加新的Agent类型
1. 更新 `models/agent.py` 中的 `AgentType`
2. 在 `prompt_templates.yaml` 中添加默认配置
3. 更新 `config/prompt_templates_loader.py`

### 自定义配置加载器
```python
from config.prompt_templates_loader import load_prompt_template

# 加载自定义模板
template = load_prompt_template('custom_template')
```
