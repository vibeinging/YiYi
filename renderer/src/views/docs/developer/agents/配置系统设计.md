# Agent配置系统设计方案

## 项目概述

### 背景与目标
当前系统中的Agent配置（Prompt配置和业务规则）分散在不同的tab页面，缺乏统一管理。需要：
1. 将PromptConfig和BusinessRulesManager合并为一个统一的Agent设置页面
2. 简化规则机制，去除复杂的召回逻辑
3. 通过占位符机制将规则动态插入到System Prompt中
4. 支持模型配置和用户绑定

## 核心设计原则

1. **简洁性**：规则简化为纯文本，不需要召回逻辑
2. **统一管理**：所有Agent相关配置集中管理
3. **灵活性**：通过占位符实现动态内容注入
4. **可扩展**：易于添加新的Agent类型

## 数据模型设计

### 1. Agent模型（新）

**文件**: `backend/models/agent.py`

```python
class Agent(BaseModel):
    __tablename__ = "agents"

    # 基础字段
    id = Column(Integer, primary_key=True)
    name = Column(String(200), nullable=False)
    agent_type = Column(String(100), nullable=False)  # nl2sql, question_enhancement, entity_replacement

    # 关联字段
    database_connection_id = Column(Integer, ForeignKey('database_connections.id'), nullable=True)
    user_id = Column(Integer, ForeignKey('users.id'), nullable=False)

    # 模型关联
    model_id = Column(Integer, ForeignKey('models.id'), nullable=True)  # 关联到已有的模型表

    # 提示词
    system_prompt = Column(Text)  # 包含{rules}占位符
    user_prompt_template = Column(Text)

    # 规则（纯文本）
    rules = Column(Text, nullable=True)  # 纯文本规则，通过{rules}占位符插入

    # 状态
    is_active = Column(Boolean, default=True)
    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
```

### 2. 模型关联说明

Agent通过`model_id`字段关联到已有的模型表，支持：
- 关联到具体的LLM模型（如GPT-4、Claude等）
- 模型信息从已有的models表读取
- 不需要重复存储模型配置信息

## 后端API设计

### 1. Agent服务层

**文件**: `backend/api/services/database/agent_service.py`

主要方法：
- `create_or_update_agent()` - 创建或更新Agent
- `get_agent_by_type()` - 获取特定类型的Agent
- `compile_prompt()` - 编译最终prompt（替换{rules}占位符）

### 2. API路由

**文件**: `backend/api/v1/routes/agents.py`

```
GET    /api/v1/agents/{user_id}/{agent_type}  # 获取Agent配置
POST   /api/v1/agents/{user_id}/{agent_type}  # 创建/更新Agent
POST   /api/v1/agents/{agent_id}/compile       # 编译prompt
```

## System Prompt占位符机制

### 占位符定义
- `{rules}` - 业务规则占位符
- 可扩展其他占位符：`{database}`、`{schema}`、`{examples}`等

### 示例

```python
# System Prompt示例
system_prompt = """你是一个专业的SQL生成助手。

根据用户的自然语言问题，生成对应的SQL查询语句。

{rules}

请严格按照以下要求生成SQL：
1. 确保语法正确
2. 只生成SQL语句，不要解释
3. 使用合适的表名和字段名
"""

# 编译时将{rules}替换为实际的rules内容
```
