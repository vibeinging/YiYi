# 业务语义管理重构文档

## 概述

本文档描述了将业务语义管理功能从数据库模块迁移到业务模块的重构工作。此次重构将语义实体、业务指标、样例数据等功能整合到业务配置中，使业务语义的管理更加集中和直观。

## 背景与动机

### 原有问题
1. 语义管理功能分散在数据库模块中，与业务概念脱节
2. 用户需要在不同页面间切换才能完成业务相关的语义配置
3. 业务数据源和业务语义的管理入口不统一

### 改进目标
1. 将语义管理功能整合到业务模块，形成完整的业务配置视图
2. 统一业务相关的数据源和语义管理入口
3. 优化用户操作流程，减少页面跳转

## API 设计

### 新增路由

所有业务语义API路径格式为：`/api/projects/{project_id}/businesses/{business_id}/...`

#### 指标管理
| 方法 | 路径 | 描述 |
|------|------|------|
| POST | `/metrics` | 创建指标 |
| GET | `/metrics` | 获取指标列表 |
| PUT | `/metrics/{metric_id}` | 更新指标 |
| DELETE | `/metrics/{metric_id}` | 删除指标 |
| POST | `/metrics/generate_embeddings` | 生成指标向量 |
| POST | `/metrics/bulk_import` | 批量导入指标 |
| GET | `/metrics/search` | 搜索指标 |

#### 样例数据管理
| 方法 | 路径 | 描述 |
|------|------|------|
| POST | `/examples` | 创建样例 |
| GET | `/examples` | 获取样例列表 |
| PUT | `/examples/{example_id}` | 更新样例 |
| DELETE | `/examples` | 批量删除样例 |
| POST | `/examples/generate_embeddings` | 生成样例向量 |

#### 语义实体管理
| 方法 | 路径 | 描述 |
|------|------|------|
| POST | `/entity_configs` | 创建实体配置 |
| GET | `/entity_configs` | 获取实体配置列表 |
| PUT | `/entity_configs/{config_id}` | 更新实体配置 |
| DELETE | `/entity_configs/{config_id}` | 删除实体配置 |
| POST | `/entity_configs/generate_embeddings` | 生成实体向量 |
| POST | `/entity_configs/import_excel` | Excel导入实体 |

### 权限要求

所有业务语义API都需要 `datasource_manage` 权限：
```python
from api.dependencies import require_data_manage

@router.post("/metrics")
async def create_metric(
    project_id: str,
    business_id: str,
    data: MetricCreate,
    user_id: str = Depends(require_data_manage),
    db: AsyncSession = Depends(get_db)
):
    ...
```

## 数据模型

### MetricDefinition（指标定义）
```python
class MetricDefinition(BaseModel):
    __tablename__ = "metric_definitions"

    id = Column(String(36), primary_key=True)
    business_id = Column(String(36), ForeignKey('businesses.id'))
    source_id = Column(String(36))  # 数据源ID
    source_type = Column(String(50))  # database/structured_data_source
    name = Column(String(200))
    sql_template = Column(Text)
    description = Column(Text)
    related_tables = Column(JSON)
    related_columns = Column(JSON)
    is_active = Column(Boolean, default=True)
    has_embedding = Column(Boolean, default=False)
```

### Example（样例数据）
```python
class Example(BaseModel):
    __tablename__ = "examples"

    id = Column(String(36), primary_key=True)
    business_id = Column(String(36), ForeignKey('businesses.id'))
    source_id = Column(String(36))  # 可选，关联数据源
    source_type = Column(String(50))
    example_type = Column(String(20))  # sql/pandas
    question = Column(Text)
    content = Column(Text)
    description = Column(Text)
    has_embedding = Column(Boolean, default=False)
```

### EntityMappingConfig（实体映射配置）
```python
class EntityMappingConfig(BaseModel):
    __tablename__ = "entity_mapping_configs"

    id = Column(String(36), primary_key=True)
    business_id = Column(String(36), ForeignKey('businesses.id'))
    source_id = Column(String(36))
    source_type = Column(String(50))
    import_type = Column(String(20))  # database/excel
    config_name = Column(String(200))  # Excel导入时的配置名
    table_name = Column(String(200))
    column_name = Column(String(200))
    metadata_fields = Column(JSON)
    rule = Column(Text)
    is_active = Column(Boolean, default=True)
    entity_count = Column(Integer)
    vector_count = Column(Integer)
```

### 组件说明

#### EntityManager（语义实体管理）
- 支持从数据库提取实体
- 支持Excel导入实体
- 显示实体数量和向量化状态
- 支持单独/批量生成向量

#### MetricManager（业务指标管理）
- 创建/编辑指标
- SQL模板配置
- 关联表/列管理
- Excel批量导入指标
- 向量化状态管理

#### ExampleManager（样例数据管理）
- 创建SQL/Pandas样例
- 样例类型筛选
- 向量化状态管理
- 批量生成向量

## 迁移指南

### 数据迁移

现有数据无需迁移，新架构通过 `business_id` 外键关联业务。

### 代码迁移

#### 后端服务层
原 `database_service.py` 中的语义相关服务拆分为独立服务：
- `EntityService` - 实体管理
- `MetricService` - 指标管理
- `ExampleService` - 样例管理

#### 前端组件
1. 复制组件到 `views/business/components/`
2. 修改API调用路径
3. 调整权限检查
4. 更新路由和props传递
