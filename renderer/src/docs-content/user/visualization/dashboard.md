# Dashboard 管理

Dashboard 用于集中展示和共享查询结果。它适合用于持续查看关键指标、组织多个结果视图，以及将常用分析内容沉淀为固定页面。

> **权限要求**：需要 `report_manage`（报表管理）权限
>
> **谁有这个权限**：项目管理员、报表管理员角色

## 进入 Dashboard 管理页面

**操作路径**：`侧边栏` → `Dashboard`

## 什么是 Dashboard

一个 Dashboard 通常由多个数据面板组成。

- Dashboard：一个完整的数据看板页面
- 数据面板：看板中的单个结果区域，例如表格或图表

通过将多个数据面板组织在同一页面中，你可以把同一业务主题下的关键结果放在一起查看。

## 什么时候适合创建 Dashboard

以下场景通常适合使用 Dashboard：

- 需要长期查看固定指标
- 需要将多个查询结果组合成同一主题页面
- 需要向团队成员共享常用分析结果
- 需要在项目内沉淀稳定的展示视图

## 创建 Dashboard

1. 进入 Dashboard 管理页面。
2. 新建 Dashboard。
3. 填写名称。
4. 根据需要补充说明信息。
5. 保存创建。

## 添加数据面板

数据面板通常有两种来源。

### 从对话结果保存

1. 先在[Agent 工作区提问](/docs/user/getting-started/quickstart)中获得可用结果。
2. 将结果保存为数据面板。
3. 在 Dashboard 中选择并添加该数据面板。

### 从已有数据面板中复用

如果项目中已经存在可复用的数据面板，可直接将其加入当前 Dashboard。

## 调整布局

创建 Dashboard 后，可调整数据面板的位置和大小，使相关内容更便于同时查看。

布局调整时，建议优先遵循以下原则：

- 同一主题的数据面板放在相近位置
- 汇总结果优先放在上方
- 明细表格和辅助信息放在下方或侧边

## 日常使用中的常见操作

### 查看 Dashboard

进入目标 Dashboard 后，可直接浏览各数据面板的结果内容。

### 刷新结果

若页面提供刷新入口，可在需要时手动刷新当前结果。对于依赖频繁更新数据的页面，也可按实际场景安排更新频率。

### 编辑 Dashboard

当需要新增、删除或调整数据面板时，可进入编辑状态进行修改。

### 删除 Dashboard

如果某个 Dashboard 不再使用，可将其删除。删除前建议确认其中的布局和展示结果是否仍有保留价值。

## 如何设计更易用的 Dashboard

- 一个 Dashboard 应聚焦单一主题，不宜混入过多无关内容。
- 先放最重要的指标，再放拆分结果和说明性内容。
- 对需要频繁查看的结果，优先使用稳定口径和清晰命名。
- 如果某个页面已经过长，可考虑拆分为多个专题 Dashboard。

## 注意事项

- Dashboard 适合展示已确认口径的结果，不建议直接承载未经核对的临时分析。
- 如果底层查询逻辑变化，相关数据面板的展示结果也可能随之变化，应定期检查。
- 对团队共享的 Dashboard，建议统一命名方式和说明文字，避免误解。
