# 登录与注册

本页介绍 YiW 的登录和注册方式，以及首次进入系统后可能遇到的常见情况。

## 登录

访问系统首页，如果未登录，系统会自动跳转到登录页面。

### 登录方式

使用 **用户名/邮箱** + **密码** 进行登录：

1. 在「用户名」输入框中输入你的用户名或注册邮箱
2. 在「密码」输入框中输入密码
3. 点击「登录」按钮

### 登录后跳转

登录成功后，系统通常会根据当前身份和最近访问记录进入相应页面：

| 用户类型 | 跳转位置 |
|---------|---------|
| 系统管理员 | 系统管理后台 |
| 普通用户（有上次项目记录） | 上次访问的项目 |
| 普通用户（首次登录） | 项目选择页面 |

## 注册

YiW 采用邀请码注册机制。若你的组织开启该机制，需要先从管理员处获取有效邀请码，再完成账号注册。

> **获取邀请码**：请联系你的系统管理员获取有效的邀请码。

### 注册步骤

1. 在登录页面点击「立即注册」链接
2. 填写注册信息：

| 字段 | 要求 | 说明 |
|-----|-----|-----|
| 邀请码 | 必填 | 管理员提供的有效邀请码 |
| 用户名 | 必填，3-20位 | 登录时使用的唯一标识 |
| 密码 | 必填，至少6位 | 建议使用强密码 |
| 确认密码 | 必填 | 需与密码一致 |

3. 点击「注册」按钮完成注册
4. 注册成功后自动返回登录页面，使用新账号登录

### 邀请链接注册

如果你收到包含邀请码参数的注册链接，打开后通常会直接进入注册页面，并自动填充邀请码。此时只需补充用户名和密码即可完成注册。

## 安全说明

### 密码安全

- 密码在传输前会进行加密处理
- 建议使用包含字母、数字、特殊字符的强密码
- 定期更换密码以确保账号安全

### 登录保护

- 系统会记录登录状态，关闭浏览器后需重新登录
- 长时间无操作会自动退出登录
- 在公共设备上使用后，建议主动退出登录

## 常见问题

### 忘记密码怎么办？

目前系统暂不支持自助找回密码，请联系系统管理员重置密码。

### 邀请码无效？

- 检查邀请码是否输入正确（注意大小写）
- 邀请码可能已过期或已被使用
- 联系管理员确认邀请码状态

### 用户名已存在？

用户名是系统唯一标识，如果提示已存在，请更换一个用户名重试。
