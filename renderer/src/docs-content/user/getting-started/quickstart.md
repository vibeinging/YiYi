# 快速开始

本指南用于帮助首次使用 YiW 的用户完成最基本的准备工作，并发起第一条查询。

如果你是项目管理员或负责环境配置的成员，建议完整阅读本页。如果你只是普通查询用户，可重点阅读“开始查询”部分，并确认项目管理员已提前完成模型和数据源配置。

## 使用前准备

开始前，请先确认以下事项：

- 你已经拥有可用账号，并可正常登录系统。
- 你已经加入目标项目，或具备创建项目权限。
- 如果需要自行配置模型和数据源，你的角色还应具备对应管理权限。

## 步骤一：进入或创建项目

### 进入已有项目

如果你已经被邀请加入项目，登录后可在项目列表中直接选择并进入该项目。

### 创建新项目

如果你具备创建项目权限，可在项目选择页面创建新项目：

1. 点击「创建新项目」。
2. 填写项目名称。
3. 根据需要补充项目描述。
4. 提交后进入新项目。

创建完成后，创建者一般会成为该项目的项目管理员。

## 步骤二：配置模型

> **权限要求**：`model_service_manage`

在开始Agent 工作区提问前，项目中至少需要配置一个可用的对话模型。若项目还需要文档检索或向量化能力，还应配置嵌入模型。

### 操作路径

`侧边栏` → `模型配置` → `模型管理`

### 配置对话模型

1. 进入模型管理页面。
2. 在对话模型区域添加新模型。
3. 填写模型名称、服务商、模型标识、API 地址和 API 密钥等信息。
4. 进行连接测试。
5. 测试通过后保存，并将目标模型设为激活状态。

### 何时需要配置嵌入模型

在以下场景中，通常还需要配置嵌入模型：

- 使用非结构化数据源
- 使用结构化数据源中的语义检索能力
- 需要基于文档内容进行召回和问答

如果你的项目仅使用数据库进行基础查询，可先完成对话模型配置，再根据需要补充嵌入模型。

## 步骤三：添加数据源

> **权限要求**：`data_manage`

### 常见起点：数据库

对于多数项目，数据库是最常用的数据源类型。建议先完成数据库接入，再逐步补充其他数据源。

### 操作路径

`侧边栏` → `业务管理` → `数据库管理`

### 基本步骤

1. 新建数据库连接。
2. 选择数据库类型。
3. 填写主机、端口、数据库名、用户名和密码等连接信息。
4. 测试连接并保存。
5. 同步表结构，确认目标表已正确加载。

### 配置完成后应检查什么

添加数据库后，建议至少确认以下内容：

- 连接测试已通过。
- 需要使用的表已经同步成功。
- 不希望参与查询的表未被选入。
- 表和字段名称可被后续业务配置正确识别。

## 步骤四：补充业务语义配置

> **权限要求**：`data_manage`

业务语义配置不是强制步骤，但它会直接影响系统对问题的理解质量。对于字段命名不直观、业务术语复杂或指标口径要求严格的场景，建议尽早补充。

### 为什么建议尽早配置

如果底层字段名称采用技术命名，例如 `usr_nm`、`ord_amt`，系统很难仅根据字段原名推断其业务含义。为表和字段补充业务名称、说明和示例后，通常能提升查询的稳定性和准确性。

### 建议优先配置的内容

- 核心业务表的业务名称
- 高频使用字段的业务名称和说明
- 关键指标的计算口径
- 常见业务问题对应的样例数据

如果时间有限，建议先覆盖最常用的表和字段，再逐步补齐其余内容。

## 步骤五：开始查询

> **权限要求**：`ask_data`

### 操作路径

`侧边栏` → `智能问数`

### 基本步骤

1. 进入对话页面。
2. 在输入框中输入问题。
3. 发送问题并等待结果返回。
4. 根据结果判断是否需要继续追问、调整条件或查看 SQL。

### 示例问题

建议从明确、范围清晰的问题开始，例如：

```text
最近 7 天的订单量是多少？
上个月的销售额是多少？
北京地区本季度新增用户数是多少？
销售额最高的前 10 个产品有哪些？
```

### 如何判断当前结果是否可用

收到结果后，建议至少核对以下几点：

- 时间范围是否符合预期。
- 指标口径是否正确。
- 返回的维度和筛选条件是否完整。
- 若结果异常，是否需要查看 SQL 或补充业务语义配置。

## 各步骤权限汇总

| 步骤 | 所需权限 | 常见执行者 |
|-----|---------|-----------|
| 创建项目 | 创建项目权限 | 系统管理员或获授权成员 |
| 配置模型 | `model_service_manage` | 项目管理员或模型管理角色 |
| 添加数据源 | `data_manage` | 项目管理员或数据管理员 |
| 补充业务语义 | `data_manage` | 项目管理员或数据管理员 |
| 发起查询 | `ask_data` | 所有具备查询权限的成员 |

## 常见开始方式

### 作为项目管理员

建议按“项目 → 模型 → 数据源 → 业务语义 → 查询”的顺序完成初始配置。

### 作为普通查询用户

如果项目管理员已经完成配置，你只需要：

1. 进入项目。
2. 打开 Agent 工作区。
3. 使用明确的问题开始查询。
