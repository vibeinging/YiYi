# 项目管理

项目是 YiW 中组织数据、成员和配置的基本单元。登录后，用户通常需要先进入某个项目，才能继续使用查询、配置和可视化等功能。

## 项目选择页面

登录成功后，普通用户通常会进入项目选择页面。在该页面中，你可以查看自己有权限访问的项目，并根据需要进入已有项目或创建新项目。

### 页面内容

- **项目列表**：显示你有权限访问的所有项目
- **当前项目标识**：如果之前访问过某个项目，会高亮显示
- **创建项目入口**：如有权限，可以创建新项目
- **搜索功能**：快速查找项目

### 项目卡片信息

每个项目卡片显示：

| 信息 | 说明 |
|-----|-----|
| 项目名称 | 项目的显示名称 |
| 角色 | 你在该项目中的角色 |
| 描述 | 项目的简要说明 |
| 创建时间 | 项目创建日期 |

## 进入项目

点击任意项目卡片即可进入该项目。进入后：

- 系统会记住你的选择
- 下次登录会优先显示该项目
- 可以访问项目内的所有功能（根据权限）

### 切换项目

在项目内部时，可以通过以下方式切换：

1. 点击左上角的项目名称
2. 选择「切换项目」
3. 返回项目选择页面

## 创建项目

### 权限要求

创建项目需要具备「创建项目」权限。该权限通常由系统管理员分配。

### 创建步骤

1. 在项目选择页面点击「创建新项目」卡片
2. 填写项目信息：

| 字段 | 要求 | 说明 |
|-----|-----|-----|
| 项目名称 | 必填，2-100字符 | 项目的显示名称 |
| 项目描述 | 选填，最多500字符 | 描述项目用途和范围 |

3. 点击「创建」按钮

### 创建后

- 你将自动成为该项目的**项目管理员**
- 拥有项目内的全部权限
- 系统会进入新创建的项目

## 项目设置

进入项目后，可在「项目设置」中查看和管理项目的基本信息、成员和角色配置。

### 基本信息

修改项目名称和描述：

1. 进入「项目设置」→「基本信息」
2. 修改项目名称或描述
3. 点击「保存」

### 成员管理

邀请和管理项目成员：

1. 进入「项目设置」→「成员管理」
2. 可进行的操作：
   - **邀请成员**：生成邀请链接或直接添加
   - **修改角色**：调整成员的权限角色
   - **移除成员**：将成员从项目中移除

> **详细说明**：查看 [成员管理](/docs/user/project/members) 文档

### 角色配置

管理项目角色：

1. 进入「项目设置」→「角色管理」
2. 可进行的操作：
   - 查看预置角色
   - 创建自定义角色
   - 配置角色权限

> **详细说明**：查看 [角色与权限](/docs/user/project/roles) 文档

## 退出登录

在项目选择页面底部，点击「退出登录」可以安全退出系统。

## 常见问题

### 没有项目怎么办？

如果项目列表为空：

- **有创建权限**：点击「创建新项目」创建第一个项目
- **无创建权限**：联系管理员邀请你加入现有项目

### 找不到之前的项目？

可能原因：

- 你已被移出该项目
- 项目已被删除
- 搜索条件过滤了该项目

建议：清空搜索框，或联系项目管理员确认。

### 无法创建项目？

如果没有看到「创建新项目」选项：

- 你没有「创建项目」权限
- 联系系统管理员申请权限
