# 产品介绍

YiW 是面向团队协作的数据分析平台，用于将数据接入、业务配置、对话分析和结果展示组织在同一工作空间内。它适合需要在同一项目中完成查询、分析、共享和协作的团队。

如果你是第一次使用，建议先完成账号登录与项目进入，再按照“模型配置、数据接入、业务配置、Agent 工作区提问”的顺序开始。

## 你可以用它做什么

- 通过自然语言查询业务数据
- 管理项目中的数据源和模型配置
- 统一关键业务术语和指标口径
- 将常用结果整理为 Dashboard 共享给团队成员

## 支持的数据与配置范围

在一个项目中，可以接入并管理以下内容：

- 关系型数据库
- 文档类数据源
- API 或表格类结构化数据源
- 网络搜索能力
- 标准名词、业务指标和样例数据
- 项目成员、角色和权限

这些能力共同决定了系统如何理解业务问题，以及团队如何在同一项目内协作。

## 推荐的开始路径

如果你是第一次使用，建议按以下顺序开始：

1. 创建或进入项目。
2. 配置模型并接入数据源。
3. 补充业务配置，使术语和指标口径更清晰。
4. 进入 Agent 工作区发起问题。
5. 将常用结果整理为 Dashboard。

## 使用前建议

开始之前，建议先确认：

- 你已经加入目标项目
- 当前项目已具备可用模型和数据源
- 你的角色与当前工作职责相匹配

如果你只负责查询分析，无需先学习全部配置细节。
