# 名词解释

本页用于解释 YiW 中常见的用户侧术语。为避免与开发实现混淆，本页优先使用产品和业务视角说明概念，而不展开内部实现细节。

## 基础概念

| 术语 | 说明 |
|------|------|
| 项目 | 工作空间，用于组织数据源、模型、成员和展示结果 |
| 成员 | 被授予项目访问权限的用户 |
| 角色 | 一组权限配置，用于决定成员可以访问哪些页面和执行哪些操作 |
| 权限 | 对应具体操作能力的控制项，例如数据查询、数据管理或成员管理 |

## 数据与业务

| 术语 | 说明 |
|------|------|
| 数据源 | 项目中的数据入口，可以是数据库、文档、接口或网络搜索能力 |
| 数据库 | 以表结构组织的结构化数据来源 |
| 非结构化数据源 | 以文档内容为主的数据来源，例如 PDF、Word 或 Markdown |
| 结构化数据源 | 不直接来自传统数据库、但仍具备字段结构的数据来源，例如接口或表格文件 |
| 网络数据源 | 用于补充互联网公开信息的检索能力 |
| 业务配置 | 对表、字段、指标和常见问法进行业务层整理的配置集合 |
| 标准名词 | 为表、字段或对象补充业务名称和说明的配置 |
| 业务指标 | 对重要指标的计算口径进行明确和固化的配置 |
| 样例数据 | 用于帮助系统理解常见问法和查询思路的示例配置 |

## 模型相关

| 术语 | 说明 |
|------|------|
| 对话模型 | 用于理解问题、生成分析结果和辅助查询的模型 |
| 嵌入模型 | 用于文本向量化、相似度计算和语义召回的模型 |
| API 密钥 | 调用模型或外部服务时使用的认证信息 |
| 模型服务商 | 提供模型服务的厂商或平台 |
| 向量化 | 将文本内容转换为可用于相似度计算的表示形式 |
| 语义召回 | 按内容含义而不是仅按关键词进行匹配和检索 |

## 查询与结果

| 术语 | 说明 |
|------|------|
| Agent 工作区提问 | 通过自然语言发起分析任务的页面和交互方式 |
| 会话 | 围绕同一主题进行的一组连续问答记录 |
| Agent 对话列表 | 已完成或进行中的会话列表 |
| SQL | 用于查询数据库的语言，在部分结果场景中可供查看和核对 |

## 可视化与协作

| 术语 | 说明 |
|------|------|
| Dashboard | 用于展示和共享查询结果的数据看板 |
| 数据面板 | Dashboard 中的单个结果区域，例如表格或图表 |
| 成员管理 | 管理项目成员加入、角色调整和移除的页面 |
| 项目配置 | 查看项目基础信息及进入相关设置模块的入口页面 |

## 权限代码

| 权限代码 | 说明 |
|----------|------|
| `ask_data` | 发起Agent 工作区提问、查看Agent 对话列表 |
| `data_manage` | 管理数据库、业务配置和数据源 |
| `model_service_manage` | 管理对话模型和嵌入模型 |
| `report_manage` | 创建和管理 Dashboard |
| `member_manage` | 邀请成员、调整角色、移除成员 |
| `project_admin` | 管理项目级配置和关键设置 |
