# 常见问题

本页汇总了使用 YiW 时较常见的问题。若某个问题仍无法解决，建议联系项目管理员或负责维护当前部署环境的团队进一步排查。

## 账号与登录

### 如何注册账号

如果当前系统启用了邀请码注册，你需要先从管理员处获取有效邀请码，再完成注册。具体流程可参考[登录与注册](/docs/user/getting-started/login)。

### 忘记密码怎么办

如果系统未提供自助找回能力，请联系系统管理员协助重置密码。

### 登录后看不到任何项目

常见原因包括：

- 你尚未被邀请加入任何项目
- 你有创建项目权限，但尚未创建项目
- 之前可访问的项目已被删除或你已被移出该项目

建议先确认当前账号是否正确，再联系项目管理员核实项目成员关系。

### 如何切换项目

如果当前账号可以访问多个项目，可在项目切换入口中重新选择目标项目。具体流程可参考[项目管理](/docs/user/getting-started/project)。

## 权限与页面访问

### 为什么我看不到某些菜单

页面是否可见取决于当前角色。若缺少相应权限，你可能无法看到模型配置、数据管理、Dashboard 或成员管理等页面。

如需进一步确认，可参考[角色与权限](/docs/user/project/roles)。

### 我可以自己提升权限吗

一般不能。角色和权限调整通常需要由拥有成员管理权限的成员执行。

### 为什么我能进入项目，但不能修改配置

进入项目并不代表拥有全部管理权限。项目设置中的不同模块对应不同权限，具体以当前项目角色配置为准。

## Agent 工作区提问

### 查询结果不准确怎么办

建议按以下顺序检查：

1. 问题是否写清时间范围和筛选条件
2. 是否使用了团队真实采用的业务术语
3. 相关表、字段或指标是否完成业务配置
4. 返回的 SQL 或结果口径是否符合预期

如需更系统的排查方式，可参考[Agent 工作区提问](/docs/user/getting-started/quickstart)和[业务概述](/docs/user/business/overview)。

### 查询结果为空怎么办

常见原因包括：

- 当前筛选条件下确实没有数据
- 时间范围设置错误
- 条件过于严格
- 系统理解的对象与预期不一致

### 查询速度较慢怎么办

可优先尝试以下做法：

- 缩小时间范围
- 减少返回条数
- 将复杂问题拆成多个较小问题逐步查询

如果问题持续存在，建议联系管理员检查底层数据库、模型服务或网络状态。

### 是否可以导出查询结果

是否支持导出取决于当前页面能力和部署配置。如果结果页面提供导出入口，可按页面提示下载相应文件。

## 数据与模型配置

### 数据库连接失败怎么办

建议优先检查：

- 主机、端口、用户名和密码是否正确
- 当前网络是否能访问数据库
- 数据库是否允许当前地址访问
- 账号是否具备访问目标库的权限

详细说明可参考[数据库管理](/docs/user/business/database)。

### 表结构变化后如何同步

如果数据库中的表或字段发生变化，应重新执行表结构同步，以便系统使用最新元数据。

### 添加本地文档失败怎么办

常见原因包括：

- 文件格式不在支持范围内
- 文件过大
- 原文件已被移动或删除
- 文档处理超时

具体处理建议可参考[非结构化数据源](/docs/user/business/unstructured)。

### 模型测试失败怎么办

建议优先检查：

- API 地址是否正确
- 模型标识是否正确
- API 密钥是否有效
- 网络是否可访问目标模型服务

详细说明可参考[模型管理](/docs/user/models/management)。

## Dashboard 与协作

### 什么时候适合创建 Dashboard

当某类查询结果需要长期查看、共享或按主题组合展示时，适合创建 Dashboard。具体说明可参考[Dashboard 管理](/docs/user/visualization/dashboard)。

### 为什么某位成员无法看到预期页面

通常是因为该成员当前角色不包含相关权限。建议先核对角色分配是否正确，再检查是否需要调整权限。

## 其他问题

### 如何获得进一步支持

建议优先联系以下对象：

1. 当前项目管理员
2. 负责本系统部署和维护的团队

### 系统有哪些使用限制

具体限制通常取决于当前部署环境与系统配置，例如：

- 单次查询结果范围
- 文件上传大小
- 模型或搜索服务调用额度

如果需要准确限制信息，应以当前部署团队的说明为准。
