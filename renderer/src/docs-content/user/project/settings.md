# 项目配置

项目配置用于管理项目的基础信息以及与项目相关的关键设置。它也是进入成员管理、模型配置和部分数据管理能力的主要入口。

> **权限要求**：查看项目设置需要项目成员身份；修改具体配置则取决于当前功能对应的权限

## 进入项目配置页面

**操作路径**：`侧边栏` → `项目设置` → `项目配置`

## 项目配置包含哪些内容

项目设置页面通常会集中展示以下内容：

- 项目基本信息
- 成员管理入口
- 角色管理入口
- 模型配置入口
- 数据或业务相关配置入口

不同页面模块的可见性取决于成员当前拥有的权限。

## 基本信息

项目基本信息一般包括：

- 项目名称
- 项目描述

这些信息的主要作用是帮助成员识别当前项目的业务范围和用途。

## 与其他设置的关系

项目设置不仅用于查看基本信息，也是进入以下管理页面的入口：

- [成员管理](/docs/user/project/members)
- [角色与权限](/docs/user/project/roles)
- [模型管理](/docs/user/models/management)
- [业务概述](/docs/user/business/overview)

如果你看不到某些模块，一般说明当前角色未被授予对应权限。

## 修改项目前建议确认什么

在修改项目信息前，建议先确认：

- 新名称或描述是否能准确反映项目范围
- 修改后是否会影响团队成员识别项目
- 当前设置是否会影响已有协作流程

对于共享项目，建议提前与团队成员保持一致的命名和描述方式。

## 常见问题

### 为什么我能进入项目，但看不到某些设置模块

通常是因为这些模块对应更高权限的操作，例如成员管理、模型管理或数据管理。

### 项目配置和角色权限是什么关系

项目配置是页面入口和设置集合，角色权限决定你是否可以看到或修改其中的具体内容。

## 注意事项

- 项目名称和描述应保持稳定，避免频繁变更造成协作混乱。
- 对共享项目，建议使用统一、清晰的命名方式。
- 修改权限相关设置前，建议先确认影响范围。
