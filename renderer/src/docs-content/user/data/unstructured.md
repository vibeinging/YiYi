# 非结构化数据源

非结构化数据源用于管理文档类数据，例如 PDF、Word、TXT 或 Markdown 文件。它适用于以文档内容为主要信息来源的场景，例如知识库问答、制度检索、产品文档查询和研究资料归档。

> **权限要求**：需要 `data_manage`（数据管理）权限
>
> **谁有这个权限**：项目管理员、数据管理员角色

## 进入非结构化数据源页面

**操作路径**：`侧边栏` → `业务管理` → `非结构化数据源`

## 使用前准备

使用非结构化数据源前，建议先确认：

- 项目中已配置可用的嵌入模型
- 待添加文件格式在系统支持范围内
- 文档内容适合按文本段落被检索和引用
- 文档中不包含不应导入系统的敏感内容

## 适用的数据类型

非结构化数据通常包括：

- **文本文档** - PDF、Word、TXT、Markdown
- **表格文档** - Excel、CSV
- **页面内容** - 经过整理的网页文本材料

这类数据通常不具备稳定的关系型表结构，因此更适合通过文本检索和语义召回来使用。

## 前置条件

1. 进入[模型管理](/docs/user/models/management)
2. 确认项目中已有可用嵌入模型
3. 必要时先完成模型测试与激活

## 创建数据源

1. 进入非结构化数据源页面。
2. 新建数据源。
3. 填写基本信息：
   - 名称
   - 描述
   - 嵌入模型
4. 保存配置。

## 添加本地文档

创建完成后，可以选择单个本地文件，也可以批量选择多个本地文件。系统会记录文件路径并读取原文件进行处理，不会自动把原文件复制到项目工作空间。

## 常见文件格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF | `.pdf` | 最常用的文档格式 |
| Word | `.docx`, `.doc` | Microsoft Word 文档 |
| 文本 | `.txt`, `.md` | 纯文本和 Markdown |
| Excel | `.xlsx`, `.xls` | 表格数据 |
| CSV | `.csv` | 逗号分隔值 |

## 文档处理后会发生什么

添加本地文档后，系统通常会执行以下处理：

1. 从本地文件路径读取原文件
2. 提取文本内容
3. 对长文档进行切分
4. 使用嵌入模型生成向量
5. 建立可供检索的索引

文档越大、数量越多，处理时间通常越长。

## 如何验证导入是否可用

完成导入后，建议进行一次检索测试：

1. 使用与文档内容直接相关的问题进行检索。
2. 检查返回片段是否来自预期文档。
3. 确认片段内容是否足以支撑回答。

如果召回结果不稳定，通常需要检查文档质量、切分效果或嵌入模型配置。

## 管理文档与数据源

### 查看文档

在文档列表中，通常可以查看：

- 文档名称
- 添加时间
- 文件大小
- 处理状态

### 删除文档

1. 找到要删除的文档
2. 点击删除按钮
3. 确认删除

### 数据源设置

在设置页中，通常可以修改名称、描述、嵌入模型，或删除整个数据源。

## 典型使用场景

| 场景 | 说明 |
|------|------|
| 产品文档 | 查询手册、说明书、制度文件 |
| 合同与规范 | 检索条款、制度、规范文本 |
| 知识库 | 企业内部知识库检索 |
| 研究资料 | 学术论文、研究报告检索 |

## 注意事项

- 扫描版图片文档、内容过少的文件或格式混乱的文件，可能影响检索效果。
- 文档内容更新后，建议重新添加或重新处理，避免旧内容继续参与检索。
- 对于结构清晰、关系明确的数据，优先考虑数据库或结构化数据源，而不是文档型数据源。
